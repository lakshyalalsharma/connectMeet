# ConnectMeet

A real-time video conferencing and communication platform that enables users to create and join meeting rooms using a unique meeting code.

## 🚀 Features

- 🎥 Real-time video conferencing
- 🎙️ Audio communication
- 💬 Real-time chat
- 👥 Participant presence
- 🔗 Unique meeting/room codes
- 📱 Responsive interface
- 🔐 Meeting code validation
- ⚡ Real-time communication using Socket.IO
- 🌐 Peer-to-peer communication using WebRTC

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SocketIO
- JavaScript
- HTML5
- CSS3
- WebRTC
- Socket.IO
